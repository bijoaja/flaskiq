# Dokumentasi FlaskIQ

FlaskIQ adalah template proyek Flask terstruktur yang dirancang dengan arsitektur berlapis untuk pengembangan aplikasi yang bersih dan terstandarisasi.

## Indeks Dokumentasi

- [Arsitektur](architecture.md) — Desain 5 lapis (Routes → Controller → Service → Repository → Model)
- [Referensi API](api.md) — Endpoint RESTful, format request/response, dan Swagger UI
- [Autentikasi](auth.md) — Autentikasi token JWT, proteksi CSRF, dan pengamanan rute
- [Agent AI / Chatbot](agent.md) — Chatbot streaming berbasis AI (Ollama dan OpenAI)
- [Docker & Makefile](docker.md) — Pengaturan Docker dev bind-mount dan prod multi-stage
- [Panduan Kontribusi](CONTRIBUTING.md) — Standar kode, linting, pengujian, dan alur PR
